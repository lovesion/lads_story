# 每日独立创作与审校

1. 先运行 `python generator/topic_scheduler.py`，只把它当作近 30 天的避重清单，不能将其条目套成新的故事。
2. 每篇独立写一份微型 brief：角色、世界线、前提、欲望与阻力、关系推进、情绪落点、不可触碰的 OOC 红线。不要复用其他篇的情节骨架、冲突处理或句式。
3. 仅使用可确认的原作设定。原作细节无法确认时，保持场景描述克制而通用，或标注清晰 AU；不得伪造具体官方设定。
4. 写完逐篇审校：角色的选择、说话方式、亲密边界和能力表现是否能由前提与原作支撑；世界规则是否自洽；标题是否为独立短篇标题且不含编号、篇次或重复角色名。
5. 每篇正文维持 2,000–4,000 个非空白字符，填写真实 `generation_seed`，再执行两次仓库校验和索引构建。
